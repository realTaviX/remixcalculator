# 🧮 Roxy Calculator

Uma calculadora simples, personalizável e com modo científico, feita em **HTML, CSS e JavaScript puro**.

O projeto foi pensado para funcionar de forma leve e direta no navegador, sem precisar de frameworks ou bibliotecas externas.

## ✨ Funcionalidades

- Calculadora normal
- Modo científico
- Histórico de cálculos
- Histórico salvo no navegador
- Vários temas
- Cor personalizada da interface
- Papéis de parede em pixel art
- Controle de opacidade do fundo
- Suporte ao teclado
- Layout responsivo
- Favicon personalizado
- Interface simples e leve

## 🎨 Personalização

A calculadora possui diferentes opções de aparência.

Temas disponíveis:

- Escuro
- Vermelho
- Azul
- Roxo
- Verde
- Claro

Também é possível alterar manualmente a cor principal da interface.

### Papéis de parede

Os fundos disponíveis incluem:

- Gatinhos
- Estrelas
- Corações
- Nuvens
- Arcade Mix

Os desenhos são feitos em pixel art e ficam distribuídos pelo fundo da página.
